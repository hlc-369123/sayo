## 这是什么

轻述 sayo 是一个可安装在个人电脑上的**独立桌面应用**，「」这类桌面听写工具的能力：
在任意应用（浏览器、微信、Word、IDE……）中按快捷键说话，语音即时被识别、润色成通顺文字，
并自动落到当前输入框的光标位置。

**产品边界**：它的全部价值建立在「完全离线」之上——断网也能用，永远不需要服务器。
因此像「联网搜索最新信息」「云端同步个人词典」这类功能**主动不做**（详见离线承诺），
而非假装能做。

## 核心特性

| 能力 | 说明 |
| --- | --- |
| 高灵敏中英文识别 | SenseVoice-Small 本地推理，中 / 英 / 粤 / 日 / 韩自动语种，自带标点与数字 ITN；轻声、远场、噪声环境稳定 |
| 实时浮层 | 屏幕顶部中央两个**彼此独立**的透明窗口：一行实时识别文字（后续语音会回头修正前面的字）+ 随音量变化的曲线；跨应用、跨桌面、全屏应用都常驻最上层，且鼠标穿透不抢焦点 |
| 智能润色（本机规则） | 去填充词（嗯/呃/um）、去重复口吃、改口只留最终意图、口述列表自动排版、标点规范化、中英混排空格 |
| 智能整理（本机大模型） | 本地 GGUF 模型纠错 + 理顺语句 + 自动分点；**整理 ≠ 总结**，信息量与原稿一致，绝不擅自删减（过度压缩会自动重试 / 回退） |
| 一键总结 | 单独的总结窗口，把文本提炼成要点列表或短摘要 |
| 个人词典 | 人名 / 品牌 / 术语热词偏置 + 同音 / 近形纠错 |
| 语音编辑选中文字 | 选中一段文字后用语音指令改写、缩短、扩写、要点化、翻译、问答 |
| 本地历史 | SQLite 存本机，可搜索、导出、按天保留、一键清空 |
| 全局快捷键 | macOS 系统级 Carbon 热键，**不需要「输入监控」授权**，覆盖安装也不失效 |
| 完全离线 | 进程级离线锁封锁一切 IP 连接；源码可直接审计联网调用 |

## 离线承诺（务必先读）

- 模型、推理库、Qt、PortAudio **全部随安装包分发**。目标机器安装后**不需要下载任何文件**。
- 运行时没有任何 `requests / urllib / http / openai` 等调用；启动时安装**进程级离线锁**，
  禁止一切 `AF_INET/AF_INET6` 连接（只放行本机 `AF_UNIX` 进程间通信）。
- 可用两种方式复核：`python -m app.main --self-check` 与 `python scripts/verify_offline.py`
  （后者会在**封锁所有 IP 连接后**仍完成一次真实识别，证明识别不需要网络）。
- 离线锁是安全项，**安装后不可关闭**（设置界面已禁用该开关）。
- **明确不做**的事：联网搜索 / 网页打开 / 云同步 / 账号登录 / 激活校验 / 在线模型。这些在纯离线前提下存在物理边界，
  应用会直接提示，绝不伪造联网结果、绝不静默发请求。

## 运行环境要求

### 操作系统

| 平台 | 最低版本 | 架构 | 安装包形态 | 测试状态 |
| --- | --- | --- | --- | --- |
| macOS | 11 Big Sur+ | Apple Silicon / Intel x86_64 | `.app` → DMG / PKG | **主要测试平台** |
| Windows | 10 1809 / 11 | x64 | 免安装 ZIP / Inno Setup `setup.exe` | 代码支持，待更多实测 |
| Linux | glibc ≥ 2.28 | x64 / arm64 | `tar.gz` 解压即用（可选 AppImage） | 代码支持，待更多实测 |

### 硬件

| 项目 | 最低 | 推荐 |
| --- | --- | --- |
| CPU | 4 核（支持 SSE4.2/AVX 或 ARM NEON） | Apple M1 / i5 8 代 / Ryzen 3000+ |
| 内存 | 2.5 GiB 可用 | 4 GiB+ |
| 磁盘 | 2 GB 可用（完整包） | 3 GB（启用本地 LLM 额外 2–4 GB） |
| 麦克风 | 任意内置 / USB / 蓝牙，16 kHz 单声道 | 近讲降噪麦 |

**不需要** GPU / 独显 / NPU：SenseVoice 是小模型，本机实测 CPU 上即可实时；GPU 仅提供额外算力，
不改变准确率（详见[使用手册](#文档索引)与 `models/README.md`）。

### 目标机器运行时依赖

**什么都不需要**：不需要 Python、pip、Node、Docker、.NET、Java、任何模型下载、任何账号、任何联网。
所有运行时（含 Python 解释器、推理库、Qt）都随 `.app` / EXE 一起打包。

## 两种获取方式，分别怎么做

### A. 拿到「安装包」（最省事，推荐普通用户）

你拿到的是 `轻述 sayo.app` / `sayo-1.0.0-macos.dmg` / `sayo-1.0.0-macos.pkg`
（或 Windows 的 ZIP / EXE、Linux 的 tar.gz）。**直接用，不需要开发环境。**

- **macOS**
  - DMG：双击挂载 → 把「轻述 sayo」拖进「应用程序」。
  - PKG：双击按向导安装到 `/Applications`。
  - 未公证的版本（ad-hoc 签名）首次启动若被拦截：右键 → 打开，或
    系统设置 → 隐私与安全性 → 仍要打开。
  - 气密 / 断网环境：用仓库里的 `scripts/install_offline_macos.sh` 从 U 盘直接装（去 quarantine + 自动清理旧授权记录）。
- **Windows**：解压 ZIP 到任意目录双击 `sayo.exe`；或运行 Inno Setup 生成的 `setup.exe`。
- **Linux**：`tar -xzf sayo-*.tar.gz && ./sayo/sayo`，无需 root。

> 安装包里**已含语音模型**，所以装完即可用，不用再下载。

### B. 拿到「源码」（开发者 / 想自己改的人）

两种方式：

1. **直接以源码运行**（适合调试 / 二次开发）：见 [开发指南 → 从源码运行](#文档索引)。
2. **自己重新打包安装包**（适合分发 / 改完发布）：见 [开发指南 → 构建](#文档索引)。

不论哪种，源码态都需要先 `bash scripts/fetch_models.sh` 把模型拉到本地（仅构建机需要联网这一次）。

## 第一次使用（三步）

1. 启动后，菜单栏出现图标。把光标点进任意输入框。
2. 同时按 **⌘ + Shift + 空格**（键盘最下方那个空格键，左右 Command 都可以）→ 说话 → 再按一次结束。
   - 想「按住说话、松开结束」：设置 → 常规 → 勾选「按住快捷键说话」。
   - **⌘ + Shift + E** 是「语音编辑选中文字」：先选中一段文字再按。
3. 屏幕顶部中央会出现两个独立窗口：上面一行实时文字、下面几条随音量变化的曲线。
   说完再按一次快捷键，文字会自动写入输入框（需要授予「辅助功能」权限，见下）。

首次启动还会弹出「怎么用」引导窗口；也可随时从菜单栏「怎么用…」再次打开。

## 需要哪些系统权限

| 权限 | 是否必须 | 用途 | macOS 系统设置路径 |
| --- | --- | --- | --- |
| **麦克风** | 必须 | 采集语音 | 系统设置 → 隐私与安全性 → 麦克风，勾选本应用 |
| **辅助功能** | 必须（否则只进剪贴板） | 把文字自动粘贴进输入框 | 系统设置 → 隐私与安全性 → 辅助功能，勾选本应用 |
| 输入监控 | **不需要** | 本应用默认走系统级 Carbon 热键，不监听键盘流；仅当热键回退到键盘监听时才需要 | 系统设置 → 隐私与安全性 → 输入监控 |

> **关键提示**：
> - 全局快捷键**不需要任何隐私权限**即可工作（这是本应用刻意设计的，避免覆盖安装后授权失效）。
> - 未授予「辅助功能」时，文字仍会写入**剪贴板**，手动 ⌘V 即可——不会丢内容。
> - 应用会主动弹出系统授权框；授权引导窗口有「状态实时检测 + 一键打开对应设置面板」。
> - **覆盖安装后**若「辅助功能」开关明明开着却仍提示未授权：是旧签名留下的同名旧条目，
>   在设置里把旧条目删掉、用 ➕ 重新添加当前 `.app` 即可（离线安装脚本会自动 `tccutil reset` 清理）。

Windows / Linux 的权限差异见 [使用手册](#文档索引)。

## 设置项速查

设置窗口共 6 个标签页：**常规 / 识别 / 润色 / 个人词典 / 权限与隐私 / 关于**。完整逐项说明见 [使用手册](#文档索引)。
常用项：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 听写快捷键 | `cmd+shift+space` | 系统级，保存后立即重新注册，无需重启 |
| 灵敏度档位 | `high` | standard / high / max；越高越能捕捉轻声 |
| 权重精度 | `fp32` | fp32 全精度（默认、最准）/ int8（更省内存） |
| 推理后端 | `auto` | auto / cpu / gpu（Core ML / CUDA，失败自动回退 CPU） |
| VAD 阈值 | `0.32` | 越小越灵敏 |
| 智能输出 | 开 | 有输入框焦点才粘贴，否则只进剪贴板 |
| 智能整理 | 开 | 本机大模型纠错 + 分点（只润色不删减内容） |
| 主题 | `aurora` | 8 套配色，实时预览 |
| 离线锁 | 开（不可关） | 强制禁止一切出站连接 |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 按快捷键无反应 | 菜单栏「快捷键没反应？诊断 / 修复…」看注册结果；被占用就换组合键 |
| 文字只进剪贴板、不进输入框 | 授予「辅助功能」；或把光标放进输入框再听写 |
| 识别为空 / 吞字 | 灵敏度调到 `high`/`max`，开 AGC 与二次复核；确认麦克风没静音 |
| 切换应用 / 桌面后看不到浮层 | 本应用已做跨 Space 常驻；若仍消失，重启应用即可 |
| 浮层文字不动 / 曲线不动 | 检查麦克风权限与输入电平；实时预览异常见 `logs/runtime.log` |
| 翻译 / 总结提示需要模型 | 把本地 GGUF 模型放到 `~/Library/Application Support/sayo/llm/`，或设置里指定路径 |
| 覆盖安装后快捷键 / 辅助功能失效 | 见上文「权限」提示，清理旧授权条目 |

完整排查表见 [使用手册](#文档索引)。

## 二次开发与构建（简述）

- **源码运行**：需要 Python 3.10–3.12（推荐 3.11）、PySide6、sherpa-onnx、PySide 依赖；
  先 `bash scripts/fetch_models.sh` 拉模型，再 `python -m app.main`。
- **重新打包**：`bash scripts/fetch_models.sh` → `bash scripts/build_macos.sh`（或对应平台脚本）→ 产物在 `dist/`。
- **怎么改**：热键、灵敏度默认值、主题、浮层行为、ASR 模型、本地 LLM、词典、UI 各在什么文件改，见 [开发指南](#文档索引)。
- **测试**：`python -m pytest -q tests`；离线验收 `python scripts/verify_offline.py`。

完整环境、目录结构、修改点、构建细节、离线分发见 **[`docs/开发指南.md`](docs/开发指南.md)**。

## 项目结构


## 许可与安全

- 应用代码以 **MIT** 许可证发布（见 `LICENSE`）。
- 随包组件各自许可证：sherpa-onnx（Apache-2.0）、SenseVoiceSmall（Apache-2.0）、
  Silero VAD（MIT）、PySide6/Qt（LGPL/GPL，商业使用请遵循 Qt 条款）、
  PortAudio / pynput / pyperclip / pypinyin（各自开源许可）。
- **隐私**：无任何数据离开本机。所有历史、设置、可选录音仅存于用户目录，可手动导出 / 清空。
- 上游模型下载地址**只出现在构建脚本中**（构建机用），**运行时代码不引用任何外部地址**。
