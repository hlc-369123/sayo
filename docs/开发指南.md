## 一、开发环境

本项目在 **macOS（Apple Silicon / Intel）** 上构建与主要测试，Windows / Linux 通过同一套代码支持。

### 软件

| 组件 | 版本 / 说明 |
| --- | --- |
| 操作系统 | macOS 11+（构建机）；目标机 macOS 11+ / Windows 10 1809+ / Linux glibc ≥ 2.28 |
| Python | 3.10–3.13（本项目在 **Python 3.13.12** 上构建验证；推荐 3.11 / 3.12 以获得最佳的第三方库兼容性） |
| 构建工具 | git、Xcode Command Line Tools（`clang` / `codesign`，macOS 签名用）、`curl`（拉模型） |
| 打包 | PyInstaller **6.22.3**（`requirements-build.txt`） |
| 测试 | pytest ≥ 8 |
| 可选本地 LLM | `llama-cpp-python`（macOS 用 `CMAKE_ARGS="-DGGML_METAL=on"` 编译以启用 Metal GPU） |

### 关键依赖（运行时随包打包）

| 包 | 版本 | 角色 |
| --- | --- | --- |
| `sherpa-onnx` | 1.13.8 | 本地语音识别框架（含 ONNX Runtime 原生推理库） |
| `PySide6-Essentials` | ≥ 6.8, < 7 | Qt 界面 / 系统托盘 |
| `sounddevice` | ≥ 0.5.1 | 麦克风采集（自带 PortAudio 二进制） |
| `pynput` / `pyperclip` / `pypinyin` | 各自版本 | 快捷键回退 / 剪贴板 / 同音纠错 |
| `pyobjc-*`（仅 macOS） | ≥ 11 | AppKit / Quartz / AVFoundation 本机 API |
| `llama-cpp-python`（可选） | ≥ 0.3.0 | 本地 GGUF 大模型推理 |

### 磁盘

完整构建需要约 **3–4 GB** 临时空间：模型约 1.15 GB（fp32 894 + int8 228 + VAD/tokens）+ 打包中间产物。
> ⚠️ 构建脚本会把大体积临时副本移出 `dist/` 到 `/tmp/qt-build-trash-*`，反复构建可能堆积。
> 若 `/tmp` 被填满会导致打包失败，定期清理 `/tmp/qt-build-trash-*` 与 `/tmp/qt-app-*`、`/tmp/qt-collect-*` 即可。

### 网络

**只有构建机**在拉取模型时需要联网（见第四节）。目标机器运行时不联网。

## 二、源码结构（带注解）

```
entry.py                   PyInstaller 入口，仅转发到 app.main.main
app/
  main.py                  应用入口 + 控制器 + 信号桥 + CLI
                           （--cli / --file / --self-check / --benchmark）
  config.py                路径解析、默认设置 DEFAULT_SETTINGS、三档灵敏度预设
                           SENSITIVITY_PRESETS、权限说明 PERMISSION_HELP、Settings 类（JSON 落盘）
  __main__.py              支持 `python -m app.main`
  core/
    recorder.py            16k 单声道采集、电平/频谱回调、设备枚举、静音自检、读 wav
    audio_gate.py          噪声底估计 + 语音有效性门控 + 100Hz 高通 + 软噪声门 + 温和 AGC
    asr.py                 ASREngine：SenseVoice fp32/int8 / Whisper / Silero VAD /
                           二次复核 / 热词；check_models()、transcribe()
    accel.py               Core ML / CUDA 后端探测、智能调度与回退、能力摘要
    live.py                当前句增量重解码（实时预览）、FFT 频段换算
    postprocess.py         去填充词 / 去重 / 改口 / 排版 / 标点 / 语气 / 正式化替换表
    dictionary.py          个人词典：热词偏置 + 同音/近形纠错
    pipeline.py            DictationPipeline：编排 录音→识别→润色→智能整理→存储
    storage.py             SQLite：历史、词典、统计
    llm.py                 本地大模型适配层 LocalTextEngine（llama.cpp/GGUF）
                           + 确定性文本命令；organize()/summarize()/rewrite()/translate()/ask()
    offline.py             进程级离线锁 + 源码联网审计 audit_source()
  platform/
    hotkey.py              Carbon 系统级热键（免输入监控）+ pynput 回退 + 事件 tap 健康诊断
    permissions.py         本机权限查询与主动弹窗（麦克风/辅助功能/输入监控）
    inject.py              剪贴板读写 + 注入文本（paste/type）
    context.py             前台应用识别（Bundle ID / 进程名）+ 读取选中文本
    focus.py               焦点检测 + 智能输出决策（choose_output）
  ui/
    overlay.py             **两个独立透明置顶窗口**（文字 / 曲线）的跨 Space 常驻实现
    settings_window.py     6 页设置窗口（常规/识别/润色/词典/权限/关于）
    history_window.py      本地历史查看/搜索/导出/清空/重新整理
    summary_window.py      一键总结窗口（源文本可编辑、要点/摘要、复制/粘贴）
    quickstart.py          首次启动「怎么用」引导
    permission_guide.py    授权引导窗口（状态检测 + 一键打开设置）
    themes.py              8 套主题 THEMES（ aurora/晨雾/墨金/青瓷/樱粉/石墨/霓虹/海盐 ）
models/                   随包模型（fetch_models.sh 下载）+ manifest.json（SHA-256）
assets/                   图标（.icns/.ico/.png，由 make_icon.py 生成）+ 内置语音样本 sample_zh.wav
scripts/
  fetch_models.sh          【构建机】下载 fp32+int8+VAD（+可选 whisper），校验
  build_macos.sh           macOS 构建：依赖→图标→校验→测试→PyInstaller→签名→DMG/PKG
  build_windows.ps1        Windows 构建：ZIP（可选 Inno Setup）
  build_linux.sh           Linux 构建：tar.gz（+ Saylo.desktop，可选 AppImage）
  install_offline_macos.sh 离线安装：复制/去 quarantine/重签名/清理旧授权/可选启动
  verify_offline.py        离线验收：模型校验 + 源码审计 + 断网实测识别
  make_icon.py             纯代码生成各尺寸图标
packaging/
  saylo.spec           PyInstaller 规格（onedir，模型随包，可选 llama_cpp，macOS bundle）
  windows.iss              Inno Setup 安装器脚本（AllowNetworkDownloads=no）
tests/                    单元测试（约 90+ 项）+ fixtures/ 语音样本
requirements*.txt          macOS / Windows / 构建 / LLM 各自的依赖清单
```

## 三、从源码运行

```bash
cd 语言转文字输入
python -m venv .venv && source .venv/bin/activate
# macOS
pip install -r requirements-macos.txt
# Windows:  pip install -r requirements-windows.txt
# Linux:    pip install -r requirements.txt

bash scripts/fetch_models.sh          # 拉模型（需联网一次）
python -m app.main                   # 启动桌面应用
```

CLI 入口（`app/main.py`）：

```bash
python -m app.main --cli                 # 命令行交互听写（无 GUI）
python -m app.main --file 某.wav         # 离线转写本机 16k wav
python -m app.main --self-check          # 环境/权限/模型/离线锁/源码审计
python -m app.main --benchmark           # 本机 CPU/GPU × fp32/int8 实测
```

> 可用环境变量 `SAYLO_DATA`（数据目录）、`SAYLO_MODELS`（模型目录）覆盖默认路径，
> 方便并行测试互不干扰。

## 四、获取离线模型

`scripth` 只用于**构建机**：

```bash
bash scripts/fetch_models.sh            # fp32 + int8 + Silero VAD（默认包）
bash scripts/fetch_models.sh --lite     # 只 int8，省约 894 MiB（应用自动回退）
bash scripts/fetch_models.sh --with-whisper   # 额外打包 Whisper，支持 100+ 语种
bash scripts/fetch_models.sh --force    # 强制重下
```

- 下载源：SenseVoice 走 `HF_MIRROR`（默认 `https://hf-mirror.com`），
  Silero VAD / Whisper 走 `GH_MIRROR`（默认 `https://gh-proxy.com/https://github.com`）。
  可用环境变量覆盖镜像地址。
- 下载后写入 `models/manifest.json` 的 SHA-256 校验；`verify_offline.py --check-models` 会逐文件核对。
- **模型是安装包的一部分**，目标机器运行时不再下载——这是长期离线可用的关键。

## 五、如何修改（常用改动点）

下面按「想改什么 → 改哪个文件 → 怎么改」列出最常被问到的改动点。

### 改默认快捷键
`app/config.py` 的 `DEFAULT_SETTINGS`：
```python
"hotkey_dictate": "cmd+shift+space",   # macOS；其他平台默认 ctrl+shift+space
"hotkey_ask":     "cmd+shift+e",
```
格式支持 `cmd/ctrl/shift/alt + 键名`。注意避开系统保留组合（如 `⌘+Shift+A` 已被 macOS 保留，
代码里已自动迁移）。改完在设置里保存会立即重新注册，无需重启。

### 改灵敏度 / VAD 默认值
- 三档预设：`app/config.py` 的 `SENSITIVITY_PRESETS`（standard / high / max），含
  `vad_threshold` / `vad_min_silence` / `vad_min_speech` / `agc_target_peak`。
- 全局默认档位：`DEFAULT_SETTINGS["sensitivity"]`（当前 `high`）。
- ⚠️ 历史坑：默认档位与具体 VAD 参数必须对齐同一档位组，否则会出现「默认 high 但参数是 standard 组」
  的混合态，导致轻声识别不到。改默认值后请同步检查这两处。

### 改实时浮层（文字 / 曲线）行为
`app/ui/overlay.py`：
- `_FloatingWindow.apply_native()`：跨 Space 常驻、置顶、鼠标穿透的原生属性（macOS NSWindow）。
- `_TextWindow.paintEvent()`：文字描边 + 填充绘制（颜色来自主题）。
- `_WaveWindow`：曲线条数 / 振幅 / 刷新率（`set_audio` 里 `rms*40` 系数控制灵敏度）。
- `RecordingOverlay`：常驻不隐藏（`__init__` 里 `show_overlay` 后永不 `hide`）是为了保住跨 Space 注册。
- 窗口尺寸常量：`WIDTH / TEXT_HEIGHT / WAVE_HEIGHT / BAND_COUNT`。

### 改主题配色
`app/ui/themes.py` 的 `THEMES`（8 套）。每套提供文字描边 / 文字（live/final）/ 曲线 / 柔光等颜色。
新增主题后，在 `theme_items()` 里登记即可出现在设置下拉框。

### 换 / 加 ASR 模型
- 模型文件放进 `models/`（结构见 `models/manifest.json`），并在 `manifest.json` 登记 SHA-256。
- 推理封装在 `app/core/asr.py`（`ASREngine`）。新增模型类型需在 `asr.py` 与设置窗口
  `settings_window._build_asr` 的「识别模型」下拉里同步支持。
- Whisper 已预留（`--with-whisper`），但默认包不含以控制体积。

### 改 / 加本地 LLM 能力
`app/core/llm.py` 的 `LocalTextEngine`：
- 模型搜索路径：`_candidate_model_paths()` —— 设置路径 → `~/Library/Application Support/Saylo/llm/*.gguf`
  → 开发目录 `llm-models/`。**GGUF 体积大，不随应用包分发**，用户自己放。
- 整理 / 总结 / 改写 / 翻译 / 问答的 system prompt 都在本文件；整理有「长度守卫」
  （`_over_compressed` / `_floors`）防止模型过度删减——改 prompt 时务必保留这条护栏。
- 想要不同模型（如更大的 Qwen / 其他 GGUF）：用户只需换 `.gguf` 文件，代码无需改（`n_ctx=4096`，
  Apple Metal 下 `n_gpu_layers=-1` 全量上 GPU）。

### 改润色规则
`app/core/postprocess.py`：填充词表、重复/口吃规则、改口标记、排版、标点、`FORMAL_REPLACEMENTS`
（正式化替换）。开关在设置 → 润色，逐项可关。

### 改个人词典逻辑
`app/core/dictionary.py`（热词偏置 + 同音/近形纠错）+ `app/core/storage.py`（SQLite 持久化）。
UI 在 `settings_window._build_dictionary`。

### 改权限弹窗 / 输出注入
- `app/platform/permissions.py`：本机权限查询与 `AXIsProcessTrustedWithOptions` / `AVCaptureDevice`
  主动弹窗；`request_all_async` 后台申请避免抢焦点。
- `app/platform/inject.py`：剪贴板读写与 `insert_text`（paste / type 两种输出方式）。
- `app/platform/focus.py`：`choose_output` 决策（有焦点粘贴 / 无焦点剪贴板）。

### 改快捷键后端
`app/platform/hotkey.py`：优先 Carbon `RegisterEventHotKey`（免输入监控、覆盖安装不失效），
失败时回退 `pynput` / `CGEventTap`（那条路径才需要输入监控）。

## 六、各平台构建

构建 = `fetch_models`（联网一次）+ 平台 `build_*` 脚本（产物在 `dist/`）。

### macOS
```bash
bash scripts/fetch_models.sh
bash scripts/build_macos.sh
```
脚本依次：建 `.venv` → 装 `requirements-macos.txt` + `requirements-build.txt` → 生成图标 →
`verify_offline.py --check-models` → `pytest tests` → PyInstaller（用 `packaging/saylo.spec`）→
ad-hoc `codesign --deep --sign -` → 跑打包后 `--self-check` → 生成 DMG（`hdiutil`）与 PKG（`pkgbuild`）。
产物：`dist/轻述 Saylo.app`、`dist/Saylo-1.0.0-macos.dmg`、`dist/Saylo-1.0.0-macos.pkg`。

> 想做**公证分发**：在有网环境用 Developer ID 证书签名并 `xcrun notarytool` 公证后再制作离线介质。
> 本仓库默认走 ad-hoc 签名（离线优先），首次启动需用户「右键 → 打开」或系统设置放行。

### Windows（在 Windows 上跑）
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```
产物：`dist\Saylo-1.0.0-windows-x64.zip`（免安装）。若装了 Inno Setup 6，额外生成 `setup.exe`
（脚本已设 `AllowNetworkDownloads=no`，完全离线）。

### Linux（在 Linux 上跑）
```bash
bash scripts/build_linux.sh
```
产物：`dist/Saylo-1.0.0-linux-x64.tar.gz`（解压即用）+ `Saylo.desktop`。
若系统有 `appimagetool`，可进一步做 AppImage。

## 七、离线分发

- 把 `dist/` 里的安装包拷到 U 盘 / 内网介质，目标机断网安装即用。
- macOS 断网安装：`bash scripts/install_offline_macos.sh "<U盘路径>/轻述 Saylo.app" --launch`。
  脚本会复制 → 去 quarantine → 重签名 → `tccutil reset Accessibility` 清理旧授权 →（可选）启动自检。
- 升级方式：用新版本安装包整体替换（建议先核对 DMG / 模型 SHA-256），不需要在线增量更新。
- **不要**在运行时依赖任何远程资源；上游下载地址只存在于 `fetch_models.sh`（构建机）。

## 八、测试与离线验收

```bash
# 单元测试（约 90+ 项）；SAYLO_DATA 隔离数据目录
SAYLO_DATA=/tmp/qt-test python -m pytest -q tests

# 离线验收（断网实测 + 源码审计 + 模型校验）
python scripts/verify_offline.py
python scripts/verify_offline.py --check-models
python scripts/verify_offline.py --json

# 应用内自检
python -m app.main --self-check
```

`verify_offline.py` 的关键动作：先 `enforce_offline_lock()` 封锁一切出站 socket，
再跑一次真实 ASR（`tests/fixtures/zh_sample.wav`），证明识别在**完全断网**下仍可完成。
`audit_source()` 扫描源码里的联网关键字（`requests` / `urllib` / `socket.create_connection` 等），
确保没有隐藏的网络调用。

## 九、打包规格说明

`packaging/saylo.spec`（PyInstaller onedir）：
- `datas`：`models/`、`assets/` 全量随包；`collect_all` 拉入 sherpa_onnx / sounddevice / pypinyin /
  pynput / pyperclip 及其原生库；`llama_cpp` 装了才打包（可选）。
- macOS `BUNDLE`：`bundle_identifier = local.saylo.desktop`、
  `LSUIElement = True`（菜单栏常驻，不抢前台）、
  `NSMicrophoneUsageDescription` / `NSAppleEventsUsageDescription`（系统授权文案）、
  `LSMinimumSystemVersion = 11.0`。
- `excludes`：剔除 `tkinter / matplotlib / torch / tensorflow` 等不需要的重依赖，缩小体积。
- 调试控制台：环境变量 `SAYLO_DEBUG_CONSOLE=1` 可开启打包后的终端输出，便于排查。

## 十、提交与分支建议

- 模型文件（`.onnx` / `.gguf`）**不要**提交进 git（体积大且由 `fetch_models.sh` 获取；
  已在 `models/manifest.json` 登记校验和）。建议在 `.gitignore` 排除 `models/sensevoice/*.onnx`、
  `models/whisper/`、`*.gguf`、`.venv/`、`dist/`、`build/`、`__pycache__/`。
- 改默认行为（如灵敏度、快捷键）时，务必同步更新 `app/config.py` 与 `docs/使用手册.md` 的设置表，
  保持文档与实现一致。
- 新增功能若涉及联网能力，会破坏「完全离线」承诺，请在提案阶段先确认。
- 提交前跑一遍 `pytest` 与 `verify_offline.py`，确保不引入隐藏网络调用、模型仍完整。
