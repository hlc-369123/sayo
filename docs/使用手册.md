## 一、安装：拿到安装包怎么办

> 安装包**不含语音模型**：首次使用前运行一次 `install_models.command` 下载（仅这一步联网），之后永久离线。

### macOS · ZIP（最常见，最简单）

你拿到的 zip 解压后有三样东西：`轻述 sayo.app`、`install_models.command`、`使用手册.md`（本文件）。

1. 把 **`轻述 sayo.app` 拖进「应用程序」文件夹**（也能直接双击运行，但建议放进「应用程序」）。
2. **双击 `install_models.command`** → 自动下载语音模型（默认约 240 MB）到
   `~/Library/Application Support/sayo/models/` 并逐个校验，看到「完成」即可关掉窗口。
   只这一次需要联网，之后应用运行时完全离线。想要 fp32 全精度可在终端跑 `./install_models.command --full`。
3. **启动应用**：菜单栏出现图标 → 按提示授予「麦克风」与「辅助功能」权限。
4. 把光标点进任意输入框，按 **⌘ + Shift + 空格** 说话，再按一次结束；胶囊上点 ✓ 把文字写进输入框。

**如果被系统拦截**（未公证的 ad-hoc 签名，从网络下载很常见）：
- 应用：右键点 `轻述 sayo.app` → 「打开」→ 再点「打开」；或 系统设置 → 隐私与安全性 → 「仍要打开」。
- 下载脚本：右键 → 「打开」；若双击没反应，在终端执行
  `bash ~/Downloads/install_models.command`（换成你解压的实际路径）。
- 也可一次性清除隔离属性：
  `xattr -dr com.apple.quarantine "/Applications/轻述 sayo.app" ~/Downloads/install_models.command`

> 完全断网 / 气密机器：在有网机器上跑一次 `install_models.command`，把
> `~/Library/Application Support/sayo/models/` 整个目录拷到目标机器同名路径即可，无需联网。

### macOS · 其他安装形态（`.dmg` / `.pkg` / U 盘）

**方式 A · DMG（推荐）**
1. 双击 `sayo-1.0.0-macos.dmg` 挂载。
2. 把「轻述 sayo」拖到「应用程序（Applications）」文件夹。

**方式 B · PKG**
1. 双击 `sayo-1.0.0-macos.pkg`，按向导安装到 `/Applications`。

**方式 C · 气密 / 断网环境（U 盘直接装）**
```bash
bash scripts/install_offline_macos.sh "/Volumes/USB/轻述 sayo.app" --launch
```
脚本会：复制到 `/Applications` → 去除 quarantine 标记 → 重新 ad-hoc 签名 → 清理旧授权记录 →（加 `--launch` 时）跑离线自检并启动。

**关于「无法打开 / 已损坏」**
本应用默认是 **ad-hoc 签名**（未做 Apple 公证，因为公证需要联网，与离线理念冲突）。
首次启动若被 Gatekeeper 拦截：
- 右键点击 App → 「打开」；或
- 系统设置 → 隐私与安全性 → 滚动到底部点「仍要打开」。
> 这不是病毒，是 macOS 对未公证应用的常规提示。若你要企业内可信分发，可在**有网环境**用 Developer ID 签名并公证后再制作离线介质。

### Windows（`.zip` / `setup.exe`）

- **ZIP（免安装）**：解压 `sayo-1.0.0-windows-x64.zip` 到任意目录，双击 `sayo.exe`。无需管理员。
- **EXE 安装器**：运行 Inno Setup 生成的 `setup.exe`（已设 `AllowNetworkDownloads=no`，完全离线）。
- 若提示缺 VC++ 运行库：用离线介质里的 `VC_redist.x64.exe` 安装即可（不涉及联网）。

### Linux（`.tar.gz`）

```bash
tar -xzf sayo-1.0.0-linux-x64.tar.gz
./sayo/sayo          # 无需 root
# 可选：把 sayo.desktop 放进 ~/.local/share/applications 以加入应用菜单
```
需要发行版自带系统库：`libportaudio2`、`libxcb` 系列、`libxkbcommon-x11`；X11 建议装 `xdotool`。

## 二、安装：拿到源码怎么办

源码态运行**需要 Python 环境**（普通用户拿安装包即可，不用看这节）。

1. 准备 Python 3.10–3.12（推荐 3.11）。
2. 安装依赖（macOS 用 `requirements-macos.txt`，含 pyobjc；其他平台用对应文件）：
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements-macos.txt
   ```
3. 拉取离线模型（**仅这一步需要联网**，在构建 / 开发机器上做）：
   ```bash
   bash scripts/fetch_models.sh          # 默认 fp32 + int8 + VAD
   # bash scripts/fetch_models.sh --lite # 只拉 int8，省约 894 MiB
   ```
4. 运行：
   ```bash
   python -m app.main                   # 桌面应用
   python -m app.main --self-check       # 环境与离线自检
   python -m app.main --file tests/fixtures/zh_sample.wav   # 离线转写示例音频
   ```
5. 想自己重新打包安装包见 [`../开发指南.md`](../开发指南.md)。

## 三、系统权限：需要开哪些、怎么开

### macOS

| 权限 | 必须？ | 不授权会怎样 | 设置路径 |
| --- | --- | --- | --- |
| **麦克风** | ✅ 必须 | 无法录音 | 系统设置 → 隐私与安全性 → 麦克风 → 勾选「轻述 sayo」 |
| **辅助功能** | ✅ 强烈建议 | 文字只进剪贴板，需手动 ⌘V | 系统设置 → 隐私与安全性 → 辅助功能 → 勾选「轻述 sayo」 |
| 输入监控 | ❌ 不需要 | 无影响 | ——（默认 Carbon 系统热键不监听键盘流） |

**两种授权方式：**
- **自动弹窗**：首次启动 1.5 秒后，应用后台发起系统授权框（不抢输入框焦点）。
- **手动引导**：菜单栏 →「授权引导 · 文字自动输入」会弹窗，实时显示状态并提供「一键打开对应设置面板」。

**最容易踩的坑 —— 覆盖安装后权限「假失效」：**
本应用每次构建签名都会变。若你**覆盖了旧版本**，系统里可能残留多条同名「轻述 sayo」辅助功能条目，
而开关勾选的是**旧签名**那一条，于是显示「已授权」却实际未授权。
解决：在「辅助功能」里把所有「轻述 sayo」条目按 **−** 删除，再用 **➕** 重新添加当前
`/Applications/轻述 sayo.app` 并打开开关。离线安装脚本 `install_offline_macos.sh` 会先自动 `tccutil reset` 清理。

> 全局快捷键本身**不需要任何隐私权限**即可工作（系统级 Carbon 热键），这也是为什么覆盖安装不会让快捷键失效。

### Windows

- 麦克风：系统设置 → 隐私和安全性 → 麦克风，允许「桌面应用」访问。
- 辅助功能：Windows 通常不需要额外授权；若被安全软件拦截，请允许本应用模拟按键。

### Linux

- 当前用户需在 `audio` 组；PulseAudio/PipeWire 正常运行。
- X11 需 `xdotool`；Wayland 需开启相应门户权限以发送按键事件。

## 四、第一次使用（引导流程）

1. 启动后，菜单栏（屏幕右上角）出现应用图标。
2. 约 1.5 秒后，应用后台申请麦克风 / 辅助功能授权（不弹模态框、不抢光标）。
3. 首次启动会弹出「怎么用」引导窗口，介绍快捷键与浮层；之后可在菜单栏「怎么用…」重开。
4. 若辅助功能未授权，启动后会弹「授权引导」窗口，按步骤勾选即可，**无需重启**。

把光标点进任意输入框，就可以开始听写了。

## 五、日常使用完整步骤

1. **点输入框**：把光标放到你要输入文字的地方（浏览器搜索框、微信输入框、Word、IDE 都行）。
2. **按快捷键开始**：`⌘ + Shift + 空格`（键盘最下方那个空格键）。屏幕顶部中央出现两个窗口：
   - 上方一行实时文字（边说边出字，后面的语音会回头修正前面的字）；
   - 下方几条随音量起伏的曲线。
3. **正常说话**：像平时说话一样。口头禅（嗯/呃）、重复、改口都会被自动处理。
4. **按快捷键结束**：再按一次 `⌘ + Shift + 空格`。
   - 应用会做本地识别 → 润色 →（可选）智能整理 → 自动写入输入框。
   - 识别结果也会在浮层上停留约 3.5 秒供你确认。
5. **没自动写入？** 看菜单栏提示：多半是辅助功能未授权，文字已进剪贴板，手动 ⌘V 即可。

**其他入口（菜单栏图标右键 / 双击）：**
- 开始 / 结束听写
- 编辑选中文字（Ask）：选中一段文字后按 `⌘ + Shift + E`
- 模式：标准听写 / 边说边翻译 / 语音编辑问答
- 快捷键诊断、授权引导、怎么用、设置、总结最近一次听写、本机历史、退出

**按住说话（可选）：** 设置 → 常规 → 勾选「按住快捷键说话，松开即结束」，适合短句高频输入。

## 六、实时浮层说明

浮层是**两个彼此独立的透明窗口**，刻意不做成「一个大色块」：

- **文字窗口**：只有一行带描边的文字，没有背景板，在浅色 / 深色应用上都能看清。没出字时显示「正在聆听…」。
- **曲线窗口**：只有 1–4 条曲线，没有背景板；声音越小条数越少（底噪时近乎一条直线），声音越大条数越多、振幅越大；25 fps 刷新。

**行为保证：**
- 跨应用、跨桌面 Space、全屏应用都**常驻最上层**（使用 ScreenSaver 层级 + 跨 Space 行为 + 每 1 秒重申层级）。
- 完全**鼠标穿透**：点浮层所在区域的任何位置都会直达下面的输入框，不会误判成「结束听写」。
- **不抢焦点**：应用是菜单栏常驻（Accessory），永不成为前台 App，所以你的光标不会从输入框里消失。
- 浮层常驻不隐藏（切换状态只清空内容），这是为了让「跨 Space 注册」永不丢失（macOS 的已知坑）。

想关闭浮层？设置 → 常规 → 取消「录音时显示两个独立置顶窗口」。

## 七、三种工作模式

菜单栏「模式」可切换：

| 模式 | 快捷键 | 作用 | 是否需要本地 LLM |
| --- | --- | --- | --- |
| **标准听写** | `⌘+Shift+空格` | 说话 → 识别 + 润色 +（可选）智能整理 → 写入输入框 | 智能整理需要 |
| **边说边翻译** | 同上（先切模式） | 说中文，输出目标语言译文 | **需要** |
| **语音编辑 / 问答（Ask）** | `⌘+Shift+E`（先选中文字） | 对选中文字做语音指令：改写 / 缩短 / 扩写 / 要点化 / 翻译 / 提问 | 深度改写 / 问答需要 |

- **Ask 模式**即使没有本地 LLM 也能用：内置确定性命令（缩短、扩写、改成要点列表、更正式、大小写、去空格、加粗、加引号）无需模型。
- 翻译 / 深度改写 / 问答在没有本地 GGUF 模型时，会**明确提示并保留原文 / 用确定性命令**，绝不假装有联网能力。

## 八、智能整理 vs 一键总结（重要区别）

这是很多用户会混淆的两件事，本应用刻意把它们分开：

### 智能整理（听写时自动发生，默认开启）
- 目标：**整理 ≠ 总结**。逐句把口述稿转成通顺书面文字，**信息量与原稿完全一致**。
- 只做：修正错别字 / 同音字 / 口误、去掉语气词和字面重复、改口只留最终说法、按「第一/第二」自动分点。
- **绝不**：概括、省略、提炼缩写。
- **护栏**：内置「长度守卫」——若模型输出比原稿短太多（短文本 <75%、长文本 <60%），自动重试一次；
  仍过度删减则**回退到规则润色原文并提示**，绝不静默丢内容。
- 这一条来自真实反馈：「之前总结过头，留下的东西太少」。所以默认是**全保留**的整理。

### 一键总结（单独触发，默认关闭自动）
- 入口：菜单栏「总结最近一次听写…」。
- 作用：把文本压缩成**要点列表**或**短摘要**（≤100 字）。
- 这是真正的「总结 / 压缩」，是你**主动**触发的功能，不会在普通听写里自动发生。
- 源文本可编辑：默认填最近一次听写结果，也可粘贴任意文字重新总结。

一句话：**平时听写 = 信息全保留的整理；想压缩 = 手动点「总结」**。

## 九、一键总结窗口

菜单栏 →「总结最近一次听写…」打开：

1. **源文本区**：默认是最近一次听写的整理结果；可手动编辑，或点「用剪贴板文字作源」粘贴任意文字。
2. **风格**：要点列表 / 短摘要。
3. **生成总结**：由本机 GGUF 模型在后台线程生成（长文本约十几秒），结果填入结果区。
4. **输出**：「复制」或「粘贴到光标 / 替换选中文本」（目标应用有选中文字时会被替换）。
5. 若提示「未找到本机 GGUF 模型」：把模型放到 `~/Library/Application Support/sayo/llm/*.gguf`，
   或在 设置 → 润色 → 模型文件 指定路径（见开发指南的本地 LLM 一节）。

## 十、本地历史记录

菜单栏 →「本机历史…」：

- 每次听写的原文、润色后文本、来源应用、语种、耗时都会存入本机 SQLite。
- 支持：搜索、按天查看、导出 JSON、一键清空、设置保留天数（默认 365 天，0 = 永久）。
- 历史窗口里可对某条「重新整理选中（重试）」。

数据位置见第十四节。

## 十一个人词典

设置 → 个人词典：

- 三列：**标准写法 / 常见错写或别名（逗号分隔）/ 替换为（可空）**。
- 作用：识别时做**热词偏置**（让专业名词稳定识别），识别后做**同音 / 近形纠错**。
- 例：标准写法「张伟」，常见误识别「张卫,章伟」；术语「sayo」避免被写成「quiet type」。
- 整理大模型也会读取该词典（作为《专有名词表》注入），保证专有名词写法正确。

## 十二、设置全表（每一项都解释）

设置窗口共 6 个标签页。以下为逐项说明（默认值来自 `app/config.py`）。

### 常规
| 项 | 默认 | 说明 |
| --- | --- | --- |
| 听写快捷键 | `cmd+shift+space` | 系统级 Carbon 热键，**保存后立即重新注册，无需重启** |
| Ask / 编辑快捷键 | `cmd+shift+e` | 选中文字后触发语音编辑 / 问答（`⌘+Shift+A` 被系统保留，已避开） |
| 按住快捷键说话 | 关 | 开启后按住说话、松开结束 |
| 文字输出方式 | `paste` | `paste`（模拟 ⌘V）/ `clipboard_only`（只复制）/ `type`（逐字键入） |
| 粘贴后恢复剪贴板 | 开 | 用完自动还原你原来的剪贴板内容 |
| 强制离线锁 | 开（不可关） | 安全项，禁止一切出站连接 |
| 开机自动启动 | 关 | 登录时自动运行 |
| 智能输出 | 开 | 有输入框焦点才粘贴；无焦点只进剪贴板 |
| 焦点无法判断时 | `clipboard` | 微信 / Electron 等不暴露焦点控件时：`clipboard` 保守只复制 / `paste` 仍尝试粘贴 |
| 显示两个独立置顶窗口 | 开 | 实时文字 + 曲线浮层 |
| 界面主题 | `aurora` | 8 套配色，切换实时预览 |

### 识别
| 项 | 默认 | 说明 |
| --- | --- | --- |
| 识别模型 | `sensevoice` | `sensevoice`（默认，中英粤日韩）/ `whisper`（需构建时 `--with-whisper` 打包） |
| 识别语言 | `auto` | auto / zh / en / yue / ja / ko |
| 推理后端（GPU） | `auto` | auto（智能调度）/ cpu / gpu（Core ML / CUDA，失败自动回退 CPU） |
| 权重精度 | `fp32` | fp32 全精度（最准）/ int8（更省内存）/ auto |
| 灵敏度档位 | `high` | standard / high / max；越高越能捕捉轻声、远场 |
| 低电平二次复核 | 开 | 轻声 / 过短片段二次解码，换召回率 |
| 推理线程数 | `0` | 0 = 自动（最多 4） |
| 启用 VAD | 开 | Silero 端点检测，剔除静音、切分长语音 |
| VAD 灵敏度阈值 | `0.32` | 越小越灵敏 |
| 静音判定（秒） | `0.46` | 静音多久算一句话结束 |
| 说完自动结束（秒） | `0` | 0 = 手动再按快捷键结束；>0 则静音到时长自动结束 |
| 低音量自动增益 | 开 | 提升内置麦灵敏度 |
| 单次最长录音（秒） | `300` | 安全上限 |

> 切换「灵敏度档位」会**整组同步** VAD 阈值 / 静音判定 / 最短语音 / 增益；你仍可在下方滑杆微调。
> 注意：默认档位已是 `high`，VAD 参数也对齐 `high` 组——早期版本曾出现「默认 high 但参数是 standard 组」的混合 bug，会导致轻声识别不到。

### 润色
- 去除填充词 / 去除重复与口吃 / 改口只留最终意图 / 口述列表自动排版 / 标点还原 / 中英空格规范 / 个人词典：默认全开，逐项可关。
- 按应用切换语气：`auto`（按前台应用自动，如邮件=正式、微信=随意、终端=code）/ formal / casual / code / none。
- 翻译模式目标语言：默认 `en`。
- 智能整理：开（见第八节）。
- 本地 LLM：开 + 模型文件路径（见第九节 / 开发指南）。

见第十一节。

## 十三、离线自检与验收

本应用可在**完全断网**下验证自己确实不联网：

```bash
# 环境 / 权限 / 模型 / 离线锁 / 源码联网扫描
python -m app.main --self-check

# 断网实测：进程级封锁所有 IP 后仍能完成一次真实识别
python scripts/verify_offline.py

# 只校验模型完整性（SHA-256，用于验收 U 盘介质）
python scripts/verify_offline.py --check-models
```

`verify_offline.py` 会先封锁一切出站 socket，再跑一遍真实 ASR，结论「通过 · 可在完全断网环境运行」即证明识别不需要网络。

## 十四、隐私与数据位置

- **无任何数据离开本机**。所有网络调用在进程级被封锁；源码可静态审计联网关键字。
- 数据全部存于用户目录：
  - macOS：`~/Library/Application Support/sayo/`
    - `settings.json` 设置
    - `sayo.db` 历史与词典（SQLite）
    - `logs/` 各类诊断日志（hotkey.log / output.log / runtime.log / overlay.log / empty.log）
    - `llm/` 本地 GGUF 模型（你自己放的）
    - `audio/` 若开启留存录音
  - Windows：`%APPDATA%\sayo\`
  - Linux：`~/.local/share/sayo/`
- 可用环境变量覆盖：`SAYO_DATA`（数据目录）、`SAYO_MODELS`（模型目录）。
- 历史可一键清空；设置可删除文件重置。

## 十五、故障排查大全

| 现象 | 根因 / 处理 |
| --- | --- |
| 按快捷键没反应 | 菜单栏「快捷键没反应？诊断 / 修复…」看「系统热键注册」结果。被占用就换组合键（如 `cmd+shift+k`），保存即重注册。回退到键盘监听时才需要输入监控 |
| 文字只进剪贴板、不进输入框 | 辅助功能未授权。菜单栏「授权引导」按步骤勾选；或把光标放进输入框再听写 |
| 辅助功能开关开着却仍提示未授权 | 覆盖安装留下的旧签名条目。删除旧条目、重新 ➕ 添加当前 `.app`（离线安装脚本会 `tccutil reset` 自动清理） |
| 识别为空 / 吞字 | 灵敏度调到 `high`/`max`；开 AGC 与二次复核；检查麦克风输入音量；确认没在纯底噪下说话（应用会提示「未检测到有效语音」而非编造） |
| 切换应用 / 桌面后看不到浮层 | 本应用已做跨 Space 常驻；若偶发，重启应用即可（浮层常驻不隐藏，注册永不丢失） |
| 点回输入框导致听写结束 / 光标消失 | 已修复：应用为菜单栏常驻、浮层鼠标穿透。若仍发生，确认浮层窗口没有被其他「总在最前」工具遮挡 |
| 浮层文字一直不变 / 曲线不动 | 确认设置开了浮层；检查麦克风权限与输入电平；实时预览异常见 `logs/runtime.log`；识别结束后浮层一定显示最终文字 |
| 翻译 / Ask 深度改写提示需要模型 | 把本地 GGUF 模型放到 `~/Library/Application Support/sayo/llm/`，或设置里指定路径 |
| 模型缺失 | 运行 `scripts/install_models.command` 下载模型（会校验 SHA-256）；或 `python scripts/verify_offline.py --check-models` 检查完整性 |
| 内存占用高 / 冷启动慢 | 权重精度切 `int8`（常驻约 300 MiB），或用 `--lite` 构建的安装包 |
| GPU 提示加载失败 | 已自动回退 CPU，功能不受影响；CUDA 需对应驱动与带 CUDA EP 的推理库 |
| 应用无法打开（macOS 提示已损坏） | 右键 → 打开，或 系统设置 → 隐私与安全性 → 仍要打开（未公证的常规提示） |
| 想用 GPU / 比较后端 | 设置 → 识别 → 推理后端选 `gpu`；或 `--benchmark` 实测四种组合 |

更多构建 / 修改 / 测试相关内容见 [`../开发指南.md`](../开发指南.md)。
